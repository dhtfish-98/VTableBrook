# Source lineage

VTableBrook is a renamed, modular derivative of [vtable](https://github.com/0x7ff/vtable) at commit `7ffffff929983e3cc4c8155e66fd954acbb1008e`.

The original GPL-3.0 license and author notices remain. This work renames implementation bindings and splits container traversal, analysis and process entry into separate translation units; it is not an independently originated upstream project.
